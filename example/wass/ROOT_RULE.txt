# 内容目录规则 / Content folder rules

`wass/` 下的内容随登录下发给客户端，**以服务端为准**：
Content under `wass/` is sent to clients after login and **the server is authoritative**:

| 目录 Folder | 读取 Read by | 说明 Notes |
| --- | --- | --- |
| `menus/` | 菜单注册 / menu registry | 每个 `<menu>` 文件是一个独立菜单，文件名去掉 `.xml` 就是默认 id / each `<menu>` file is its own menu; the file name without `.xml` is the default id |
| `components/` | 仅 include / include only | 只能被 `<include src="components/x.xml"/>` 引用，不要写 `<menu>` 根 / referenced only by `<include src="components/x.xml"/>`; do not use a `<menu>` root |
| `js/` | 双端执行 / both sides | 按文件名字典序执行，共享同一 Rhino 作用域 / run in file name order in one shared Rhino scope |
| `json/` | 双端可读 / both sides | 名称去掉 `json/` 前缀与 `.json` 后缀 / the name drops the `json/` prefix and the `.json` suffix |
| `tex/` | 图片 / images | PNG，单张 ≤ 512KB / PNG, max 512KB each |

根目录不能放菜单 XML。修改后执行 `/wassjs reload`（OP≥2）或等待热重载。
No menu XML may sit in the root folder. After editing, run `/wassjs reload` (OP 2+) or wait for hot reload.

最小可执行窗口见 `example/minimal/`。
The minimal working window is in `example/minimal/`.
